* **Игровой движок / Платформа:** Godot Engine 4.x 
* **Язык программирования:** GDScript
* **Дополнительные инструменты:** GitHub

## Что было использовано в проекте 
* **Узлы (Nodes):** Area2D, CanvasLayer, CharacterBody2D, Timer, AudioStreamPlayer2D, Label, TileMapLayer, AnimatedSprite2D
* **Паттерны / Подходы:** Глобальный код (Global.gd), Сигналы (Signals) 
* **Ресурсы:** Спрайты по заданию, UI-шрифты
